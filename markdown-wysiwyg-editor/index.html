編集

装飾ボタンはもう一度押すと解除できます。下段は Backlog 向け機能です。出力形式を切り替えると、見出しなどの編集画面の見た目も Markdown / Backlog 寄せに変わります。

出力テキスト

「反映」で選択中の形式のテキストがここに出力されます。Markdown出力時、色・サイズ・下線などは HTML タグとして残る場合があります。

既存文面のインポート

テキストを貼り付け、上で選択中の形式として解釈し、編集画面へ読み込みます。

対応記法（概要）

  • 汎用: 見出しH1〜H6・太字・斜体・打消し・引用・リスト・表・リンク・コード・改行・Undo/Redo・書式クリア
  • 見出し表示: 出力形式に連動。Backlog / Markdown とも下線は H1・H2 のみ（H1が太く、H2は細い）。H3以降は下線なし
  • Backlog専用: 下線（___文字___）・文字色・文字サイズ（&size(n) { }）
  • Backlog専用マクロ: 目次（#contents）・Wikiリンク（[[ページ名]]）・include・rev
  • 画像・添付ファイル系は対象外です
